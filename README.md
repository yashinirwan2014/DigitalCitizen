# DigitalCitizen

1. DigitalCitizen is a Python quiz about safe and responsible digital behaviour.
2. It covers privacy, passwords and digital footprints.
3. It uses short situations based on everyday online activity.
4. It explains the suggested answer after each question.
5. It calculates the final quiz score.
6. It saves quiz attempts in a CSV history file.
7. It can display scores from previous attempts.
8. Run the project with `python main.py`.
9. It uses Python functions, lists and CSV file handling.
