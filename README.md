# DigitalCitizen
A Python quiz program about safe and responsible digital behaviour.

- Covers privacy, passwords and digital footprints.
- Uses short everyday online scenarios.
- Explains answers after each question.
- Calculates the final quiz score.
- Saves attempts in a CSV history file.
- Displays previous scores on request.

Run with `python main.py`. The project uses Python functions, lists and CSV file handling.
